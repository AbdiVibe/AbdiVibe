## Setup Instructions

<details>
<summary><b>Click to expand — required and optional steps to activate every widget above</b></summary>
<br/>

**1. Repository name (required for the stats/typing/snake widgets to work)**
All of this only renders on your profile if it lives in a repository named exactly `AbdiVibe` (i.e. `github.com/AbdiVibe/AbdiVibe`), set to **Public**. GitHub auto-detects that repo and shows its `README.md` on your profile page.

**2. Stats, streak, top languages, activity graph, trophies, typing SVG, quote card**
These are all hot-linked images from free public APIs (Vercel-hosted forks of the original projects) — nothing to install. They already point at `username=AbdiVibe` and will start working the instant this README is committed. No token, no secret, no action required.

**3. Snake contribution animation (requires one GitHub Action)**
This one needs a workflow file because it renders your contribution graph into an animated SVG on a schedule.

- Create `.github/workflows/snake.yml` in the `AbdiVibe/AbdiVibe` repo with the contents provided alongside this README (`snake.yml`).
- Go to **Settings → Actions → General** in that repo and make sure "Allow all actions and reusable workflows" is enabled.
- Go to the **Actions** tab and manually run the "Generate Snake" workflow once (`Run workflow`) instead of waiting for the schedule — this creates the `output` branch the README already links to.
- After that first run, it will refresh automatically every 24 hours.

**4. Visitor counter**
No setup needed — `komarev.com/ghpvc` counts on every render automatically once this README is public.

**5. Now Playing / Spotify (optional — off by default)**
Not enabled by default since it requires your own Spotify credentials. To turn it on:
- Fork [kittinan/spotify-github-profile](https://github.com/kittinan/spotify-github-profile) and deploy it to your own Vercel account following its README.
- Authenticate with your Spotify account through the deployed app to get your personal widget URL.
- Replace the placeholder `<details>` block in the `~/signal` section above with an `<img>` tag pointing at your deployed widget URL.

**6. Keeping the color theme consistent**
Every widget above uses the `tokyonight` theme with a `#0d1117` background and `#00D9FF` accent to match GitHub's dark mode and the terminal-inspired look of this README. If you re-theme one widget, updating `bg_color`/`theme`/`color` query params the same way across the others keeps it cohesive.

</details>
